# Vishwas Dhabhai — Academic Website

Minimal academic/research portfolio designed for GitHub Pages.

## Deploy
1. Create a GitHub repository named `yourusername.github.io` (or any repo for project Pages).
2. Upload `index.html`, `style.css`, and `resume.pdf`.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/root`.
4. Replace the placeholder GitHub and LinkedIn URLs in `index.html` with your profiles.

The site intentionally does not invent publications or research papers that are not present in the supplied resume. Add verified papers/projects as they become available.
